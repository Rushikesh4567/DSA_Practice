## 🟡 Level 2 — Range Sum

For these questions, use:

```text
sum(L, R) = prefix[R + 1] - prefix[L]
```

### 4. Range Sum

Given:

```text
arr = [2, 4, 1, 5, 3]
```

Find the sum from index `1` to `3`.

```text
L = 1
R = 3
```

Expected answer:

```text
10
```

Try calculating it using the prefix sum formula, not by directly adding the elements.

---

### 5. Multiple Range Queries

Given:

```text
arr = [5, 3, 8, 2, 7, 4]
```

Answer these queries:

```text
Query 1: L = 1, R = 3
Query 2: L = 2, R = 5
Query 3: L = 0, R = 4
```

Try to answer **all three using one prefix array**.

---

### 6. Range Sum in Java

Write a Java program that:

1. Takes an array.
2. Creates a prefix sum array.
3. Takes `L` and `R`.
4. Prints the sum from `L` to `R`.

Example:

```text
Input:
arr = [10, 20, 30, 40, 50]
L = 1
R = 3

Output:
90
```

### 12. Prefix Sum + HashMap 🔥

This is one of the most important patterns.

Given:

```text
arr = [1, 2, 3, -2, 5]
target = 3
```

Find the **number of subarrays whose sum is equal to `target`**.

For example:

```text
[1, 2]       → 3
[3]          → 3
[5, -2]      → 3
```

So the answer is:

```text
3
```

This introduces the important:

```text
Prefix Sum + HashMap
```

pattern.
